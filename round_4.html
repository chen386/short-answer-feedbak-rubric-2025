Example 0

Assumption:

Assume that variable x is a list of strings and y is a string.

Code:

def f(x, y):
    k = 0
    for e in x:
        if y.lower() == e.lower():
            k += 1
    return k

Student response:

returns the amount of times the lowercase version of string y appears in list x

Feedback:

You’re on the right track by mentioning that the function compares y in lowercase. Notice, though, that it also converts each element in x to lowercase when checking for a match. Making that point clearer will show you fully understand how the code counts occurrences ignoring case. Keep up the good work!

  • Acknowledgment: 2

  • Identification: 1

  • Suggestion: 2

Example 2

Assumption:

Assume that variable x is a list of numbers and y is a number.

Code:

def f(x, y):
    k = 0
    for e in x:
        if e % y == 0:
            k += 1

You’ve noticed that the function compares each element in the list with the variable, but try looking more closely at what e % y == 0 actually checks and how that affects the value of k. Right now, your description doesn’t cover how the loop and the accumulator k work together. It might help to walk through a small example by hand and see what’s changing with each step in the loop.

Example 9

Assumption:

Assume that the variable x is a string containing a filename for a file with a positive number on each line

Code:

def f(x):
    l = open(x).readlines()
    n = 0
    for i in l:
        if n < int(i):
            n = int(i)
    return n

Student response:

converts a file into a list and returns the smallest number in the list

Feedback:

Good start! Especially, you successfully identify the "find best pattern" within this code! Good job! A small problem is about "if n < int(i): n = int(i)". Here, if n is smaller than i, we replace n with the value of i. This means we always find a larger value in file l. Therefore, this function returns the LARGEST value intead of the smallest value.
